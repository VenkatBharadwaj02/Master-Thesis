The three Mathematica notebooks contain the numerical and analytical calculations coded to calculate the amplitudes. The "Generate Momenta.nb" is used to generate null momenta for different external states. The "Spinor-Helicity.nb" contains the definition of the spinors used to calculate the final superamplitude. This notebook need to be initialized before "Superamplitudes.nb". The "Superamplitudes.nb" begins with the initialization of Grassmann variables. It also contains the super BCFW computations to calculate 3-,4-point SQCD superamplitudes and the bootstrap approach computations (solved both numerically and anlytically) for the 5-point SQCD amplitude.
